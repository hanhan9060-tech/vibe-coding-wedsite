# 🌳 都市綠洲 - 台中公園線上影展專題 🎬
`Taichung Park Film Festival`

走進百年台中公園，透過光影鏡頭，感受自然生態與都市人文的交融。本專題影展記錄了這座百年公園的動植物生態、歷史古蹟湖心亭與當代都市人的放鬆時光。

---

## 📂 專案架構說明
本專案採用當代前端標準結構開發，包含以下核心部分：
- **`index.html`**：響應式（RWD）線上影展專題主網頁，內建多分頁切換系統。
- **Tailwind CSS**：核心美化工具，使用自訂品牌色系（`brand-50` 至 `brand-900` 藍色調）。
- **FontAwesome (v6.4.0)**：提供精美圖標支援（如：`fa-tree`, `fa-ticket`, `fa-film` 等）。
- **模擬外部樣式 (`css/styles.css`)**：內嵌客製化滾動條、過渡動畫與圖像遮罩效果。

---

## 🗺️ 網頁單元規劃 (Tabs)

1. **影展主頁總覽 (`overview`)**：影展核心精神與最新消息展示。
2. **核心放映影片 (`films`)**：精選參展紀錄片與生態影像列表。
3. **綠洲地景紀錄 (`scenes`)**：結合百年湖心亭與生態點的影像地圖。
4. **放映場次場刊 (`schedule`)**：每日電影放映時刻表與座談資訊。
5. **關於專題 (`about`)**：影展策展小組的理念與核心團隊介紹。

---

## 🚀 核心互動功能

- **免費預約觀影**：整合彈出式預約視窗（Booking Modal），提供觀眾線上索票。
- **多功能側邊欄 (Sidebar)**：
  - **行動端 (RWD)**：支援漢堡選單（Hamburger Menu），可自由拉出或摺疊。
  - **桌面端**：固定於左側，提供直覺的單元切換導覽。
- **平滑滾動與動畫**：網頁支援 `scroll-smooth` 滾動效果，切換分頁時自帶精緻的 `fadeIn` 淡入動畫。
